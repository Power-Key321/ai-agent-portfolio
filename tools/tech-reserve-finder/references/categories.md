## 匹配时常用的搜索维度

| 维度 | 搜索词构造 | 关注点 |
|------|----------|-------|
| **物理同构** | 「谁在做同样的物理操作？」 | 相变控制、等离子体、高压容器、连续分离、极限锻造 |
| **精度冗余** | 「谁的精度超出自身需求？」 | 民用级别精度是否可下移到更"低端"目标 |
| **规模冗余** | 「谁的产能规模巨大？」 | 成本摊薄到极致的工艺可否迁移 |
| **极限工况** | 「谁在更恶劣条件下做类似操作？」 | 深空、深海、核电、重工的极端经验 |
| **反常识** | 「谁的'低端'产品正好对应'高端'需求？」 | 命名隔离的产业里被忽视的能力 |

匹配完成后用 `差距评估` 步骤计算能力差值：

```
现有能力 的精度/速度/成本  vs  目标需求
  → 差值 ≤ 2 倍：直接可用
  → 差值 2-10 倍：需定制开发，基础技术已成熟
  → 差值 10-100 倍：需要定向研发，产业基础存在
  → 差值 > 100 倍：此项不适合
```

## 关于这张表

- **数据来源**：国民经济行业分类（GB/T 4754）的标准大类列表
- **「通用可迁移能力」列**：基于公开行业报告与产业常识整理，指该大类里**已量产成熟**的能力——不是单一企业的独有技术，也不是实验室阶段的能力
- **「—」行**：表示该大类的能力相对单一或分散，未发现跨产业迁移的明确抓手
- **结构设计**：本表作为 `SKILL.md` 的 `references/` 子资源，按需加载；正文中通过 `@references/categories.md` 引用
