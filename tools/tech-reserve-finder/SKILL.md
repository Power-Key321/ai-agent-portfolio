# 全产业链无意识技术储备发现器

## 核心洞见

> **很多技术难题被默认只有一条传统路线可走，但全产业链中存在大量为其他目的开发的技术储备，换个方向就能形成降维打击。这不是偶然——41 个工业大类全部具备的格局，意味着"为 A 目的开发、可解 B 问题"的技术储备无处不在。**

**这个 skill 要解决的问题**：当用户提出一个新技术难题或构想时，系统性地扫描全产业链，找到那个"已经在做同样物理操作"的产业，给出平替方案。

---

## 三步方法论

### 第一步：功能分解

将被卡技术拆解为最基础的物理/化学/数学原语（primitive）：

```
被卡技术 → 拆解为基本操作

例1：耐高压设备 → 承受极大压差且不泄漏 → 厚壁结构的应力分布控制 + 密封面设计
例2：连续化生产 → 多组分物料的不间断输送与反应 → 稳定的流量/温度/停留时间控制
例3：选择性分离 → 从复杂混合物中定向提取某一组分 → 相间分配行为的精确控制
```

**原则**：往下拆至少 3 层，直到抵达物理/化学/数学原语。不要停留在产品名称层面。

### 第二步：能力匹配

在 41 个工业大类中搜索已经在做同样物理操作的产业：

```
关键搜索词格式：
  "产业A 已有的能力" → "产业B 需要的功能"

搜索策略：
  ├── 物理同构：谁在做同样的物理操作？（相变控制、等离子体、极端压力容器、连续分离……）
  ├── 精度冗余：谁的精度超出民品需求，可以降维打击？
  ├── 规模冗余：谁的产能规模巨大，成本已摊薄到极致？
  ├── 极限工况：谁在更恶劣条件下做类似操作？（航天/深海/重工的经验）
  └── 反常识：谁的"低端"产品正好满足你的"高端"需求中某一具体子功能？
```

**41 个工业大类速查表** 见 `@references/categories.md`（按需加载）。

### 第三步：差距评估

```
当前储备的精度/速度/成本 vs 目标需求
  → 算出差值
  → 差值 ≤ 2倍：直接可用，无需任何改造
  → 差值 2-10倍：需定制开发，但基础技术已成熟
  → 差值 10-100倍：需要定向研发，但产业基础存在
  → 差值 > 100倍：此项不适合，继续搜索其他产业
```

## A/B/C 三级分类框架

不是所有"替代路线"都是无意识储备。严格区分三级：

| 级别 | 定义 | 评判标准 | 先发窗口 | 价值 |
|------|------|---------|---------|------|
| **A 级：真正无意识** | 产业A和产业B从未有过公开连接。全球范围内几乎没人想到A能解B的问题 | **Google Scholar/新闻搜不到连接**。两个产业从业人员互不知道对方在做的事 | 2-5 年 | ★★★★★ |
| **B 级：已知但供应链碾压** | 学术界知道这个方向，但独有的供应链让执行更快更便宜 | 搜得到论文/新闻，但推动者主要集中在一地，或成本结构碾压 | 1-3 年 | ★★★★ |
| **C 级：已在竞争需加速** | 全球竞争激烈，核心比拼执行速度 | 海外公司已有产品和路线图，需要追赶 | 0-1 年 | ★★★ |

### 五特征判定法

一个产业要成为候选储备，需要同时命中以下 3 条以上：

| 特征 | 判断标准 |
|------|---------|
| **物理同构** | 该产业的核心物理/化学操作与被卡技术的核心操作相同 |
| **量产成熟** | 已经大规模量产，成本已摊薄到极致 |
| **精度未开发** | 当前精度按民用标准优化，未按"高端"精度开发 |
| **产业隔离** | 该产业和目标产业之间几乎不存在人才/技术交流 |
| **供应链自主** | 该产业供应链不受外部制裁影响 |

## 4 个已验证的 A 级案例

以下案例经过完整的三步法分析和 Google Scholar 验证，确认为全球未公开连接的真正"无意识"技术储备：

### A1：固体火箭推进剂药柱界面 → 固态电池电解质界面

- **物理同构**：控制高化学势差两相之间的界面反应性——"平时绝对稳定（10-20 年储存），工作时精确可控反应"
- **储备方**：固体火箭发动机产业，数十年积累、数百种经长期贮存验证的键合剂分子库
- **被卡方**：固态电池界面稳定性（锂枝晶、循环寿命 < 1000 次）
- **影响**：固态电池界面寿命 < 1000 次 → 5000-10000 次商业化门槛

### A2：深海耐压壳体工程 → 超高压化工反应器

- **物理同构**：设计能承受极端压力（110MPa+）的容器，应力分析 / 密封设计 / 疲劳寿命的方法论完全同构
- **储备方**：载人深潜工程（11000m 级），球壳失效数据库全球独有
- **被卡方**：高压化工反应器（聚乙烯/合成氨，当前主要进口）
- **影响**：高压化工反应器从进口 → 自主设计制造

### A3：中药连续化提取工程 → 西药连续制造

- **物理同构**：从复杂多组分基质中按特定选择性连续提取目标化合物
- **储备方**：中药配方颗粒/提取物产业，数百条 GMP 产线，每天处理数百吨药材
- **被卡方**：西药连续制造（FDA 2015 年才批准首个，西方称为"制药业革命"）
- **影响**：中药成熟装备 + MES 直接迁移 → 药企连续制造从追赶变领跑

### A4：煤制油/煤化工碳化 → 下一代碳材料

- **物理同构**：控制重质有机物的热化学转化路径——从液态 → 固态碳的中间相过程
- **储备方**：煤直接液化 / 煤焦化产业，全球最大煤化工产能
- **被卡方**：硬碳负极（钠离子电池）、中间相沥青基碳纤维、多孔碳（超级电容）
- **影响**：钠电硬碳不再依赖椰壳（进口受限），碳纤维前驱体从 PAN 切换到低成本沥青路线

## 应用流程

当用户提出一个技术瓶颈或构想时，按以下流程执行：

### Phase 1: 绑定问题

```
1. 明确被卡的技术是什么
2. 目标功能是什么（不关心怎么做，只关心实现什么）
3. 当前卡在哪（具体的技术环节，不是笼统的"被卡"）
```

### Phase 2: 功能分解

```
拆解为物理/化学/数学原语，至少 3 层：
  产品名 → 子系统 → 核心物理操作 → 底层原语
```

### Phase 3: 匹配搜索

```
在 41 个工业大类中搜索：
  ├── 谁在做同样的物理操作？（物理同构）
  ├── 谁的精度更高/工况更恶劣？（降维打击）
  ├── 谁的规模更大/成本更低？（规模碾压）
  └── 关键：不要受产品名称和行业标签限制
```

### Phase 4: 分级与差距评估

```
对每个候选：
  1. Google Scholar 验证：搜"A + B"关键词组合，看是否有人提过
  2. 五特征打分：命中几条？
  3. 差距评估：当前能力 vs 目标需求，差多少？
  4. 分级：A/B/C？
```

### Phase 5: 输出建议

```
输出格式：

候选方案 1：[产业A] → [被卡技术B]
  - 物理同构：[一句话描述共同的原语]
  - 储备状态：[量产/实验室/论文阶段]
  - 差距：[差多少，可否短期弥补]
  - 分级：[A/B/C]
  - 产业隔离：[为什么不互通]

候选方案 2：...
推荐优先级排序：[A级优先，B级次之]
```

## 重要提醒

1. **不要被产品名限制**：同一个物理操作在不同产业里有完全不同的叫法——命名隔离是产业隔离的第一道墙。
2. **"低端"产业可能有"高端"能力**：中药提取看起来比西药制药"low"，但在复杂多组分连续分离这个维度上是全球第一。
3. **极端工况行业是最大的隐性技术库**：航天、深海、重型装备——这些领域在极端条件下解决过同样的问题，但和民用产业之间几乎零交流。
4. **A级价值最高但最难发现**：需要跨越两个完全隔绝的产业知识体系。B/C级更容易找到但先发窗口更短。
