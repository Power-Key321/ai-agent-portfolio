# 跨产业技术平替发现器

## 核心洞见

> **同一个物理操作，在不同产业里有完全不同的名字。** 命名差异造成了知识隔离——做提取分离的人不会去看冶金，做精密运动控制的人不会去看轨道交通。于是大量"为 A 目的开发、正好能解 B 问题"的能力，长期处于未被连接的状态。

**这个 skill 要解决的问题**：当用户提出一个技术目标或技术困境时，系统性地扫描全产业链，找到那个"已经在做同一件物理操作"的产业，给出可迁移的替代路线。

**适用场景**：技术路线调研、供应链替代方案评估、跨行业方案迁移。
**不适用**：纯信息查询、代码调试、已有明确答案的问题。

## 三步方法论

### 第一步：功能分解

把目标技术拆解为最基础的物理/化学/数学原语（primitive）：

```
目标技术 → 拆解为基本操作

例1：大规模矩阵运算 → 一组向量与一组权重做乘加 → 可控的强度调制
例2：选择性表面处理 → 控制化学反应的空间分布 → 相间分配行为的精确控制
例3：高精度定位 → 无接触地把物体稳定在目标位置 → 力场反馈与闭环控制
```

**原则**：往下拆至少 3 层，直到抵达物理/化学/数学原语。不要停留在产品名称层面——产品名称恰恰是隔离发生的地方。

### 第二步：能力匹配

在 41 个工业大类中搜索已经在做同样物理操作的产业：

```
关键搜索词格式：
  "产业A 已有的能力" → "产业B 需要的功能"

搜索策略：
  ├── 物理同构：谁在做同样的物理操作？（相变控制、等离子体、高压容器、连续分离……）
  ├── 精度冗余：谁的精度超出自身需求，可以向下迁移？
  ├── 规模冗余：谁的产能规模巨大，成本已摊薄到极致？
  ├── 极限工况：谁在更恶劣条件下做类似操作？（深空/深海/核电/重工的经验）
  └── 反常识：谁的"低端"产品正好满足你"高端"需求中的某一具体子功能？
```

### 第三步：差距评估

```
现有能力 的精度/速度/成本  vs  目标需求
  → 算出差值
  → 差值 ≤ 2 倍：直接可用，无需改造
  → 差值 2-10 倍：需定制开发，但基础技术已成熟
  → 差值 10-100 倍：需要定向研发，但产业基础存在
  → 差值 > 100 倍：此项不适合，继续搜索其他产业
```

## A/B/C 三级分类框架

不是所有"替代路线"都值得投入。严格区分三级：

| 级别 | 定义 | 评判标准 | 先发窗口 | 价值 |
|------|------|---------|---------|------|
| **A 级：连接缺失** | 两个产业之间在公开文献中少见直接连接，从业人员互不了解对方在做的事 | 公开检索难以找到把两者放在一起讨论的材料 | 2-5 年 | ★★★★★ |
| **B 级：已知但执行占优** | 方向已被讨论过，但某一方的产业基础让执行更快更便宜 | 能搜到论文或报道，但推动者集中在一地，或成本结构明显占优 | 1-3 年 | ★★★★ |
| **C 级：已在竞争** | 竞争激烈，核心比拼执行速度 | 已有厂商的产品与路线图，需要追赶 | 0-1 年 | ★★★ |

### 五特征判定法

一个产业要成为候选储备，需要同时命中以下 3 条以上：

| 特征 | 判断标准 |
|------|---------|
| **物理同构** | 该产业的核心物理/化学操作与目标技术的核心操作相同 |
| **量产成熟** | 已经大规模量产，成本已摊薄 |
| **精度未开发** | 当前精度按自身民用标准优化，未按更高精度开发 |
| **产业隔离** | 该产业和目标产业之间几乎不存在人才/技术交流 |
| **供给自主** | 该产业的能力不受单一外部供给方制约 |

## 四个已验证案例

以下案例经过完整的三步法分析，确认为公开材料中少见直接连接的跨产业迁移路线。**案例的作用是演示方法的产出形态，不是结论清单。**

### 案例 1：中药连续提取工程 → 化学药连续制造

- **物理同构**：从复杂多组分基质中，按特定选择性连续提取目标化合物
- **储备方**：中药配方颗粒与提取物产业——数百条 GMP 产线，日处理量以百吨计，连续提取装备与过程控制系统已高度成熟
- **目标场景**：化学药连续制造（2015 年后才出现首个获批产线，业内称为制药工艺的一次范式迁移）
- **可迁移点**：连续提取装备与 MES 直接迁移，开发成本远低于从零构建

### 案例 2：煤化工碳化 → 下一代碳材料

- **物理同构**：控制重质有机物的热化学转化路径——从液态到固态碳的中间相过程
- **储备方**：煤直接液化与煤焦化产业，产能规模大、工艺窗口数据积累厚
- **目标场景**：硬碳负极（钠离子电池）、中间相沥青基碳纤维、多孔碳（超级电容）
- **可迁移点**：前驱体路线可从依赖特定农业原料，转向低成本、供给更稳的沥青路线

### 案例 3：深海耐压结构工程 → 超高压化工反应器

- **物理同构**：设计能承受极端压差且零泄漏的容器——应力分析、密封设计、疲劳寿命方法论完全同构
- **储备方**：万米级载人深潜工程，积累了长周期的球壳失效数据与设计规范
- **目标场景**：聚乙烯、合成氨等超高压反应器
- **可迁移点**：从依赖进口转为自主设计与制造

### 案例 4：轨道交通牵引变流 → 大型数据中心供配电

- **物理同构**：高效、精准地把电网电能变换为负载可直接使用的直流电
- **储备方**：轨道交通牵引变流系统——大功率电能变换的长期工程积累，可靠性要求高于多数民用场景
- **目标场景**：大型数据中心供配电，多级变换累计损耗可观
- **可迁移点**：变换级数与拓扑的工程经验可直接迁移，减少中间变换环节

## 应用流程

当用户提出一个技术瓶颈或构想时，按以下流程执行：

### Phase 1: 绑定问题

```
1. 明确目标技术是什么
2. 目标功能是什么（不关心怎么做，只关心实现什么）
3. 当前卡在哪（具体的技术环节，不是笼统的"推不动"）
```

### Phase 2: 功能分解

```
拆解为物理/化学/数学原语，至少 3 层：
  产品名 → 子系统 → 核心物理操作 → 底层原语
```

### Phase 3: 匹配搜索

```
在 41 个工业大类中搜索：
  ├── 谁在做同样的物理操作？（物理同构）
  ├── 谁的精度更高 / 工况更恶劣？（向下迁移）
  ├── 谁的规模更大 / 成本更低？（规模优势）
  └── 关键：不要受产品名称和行业标签限制
```

### Phase 4: 分级与差距评估

```
对每个候选：
  1. 检索验证：搜"A + B"关键词组合，看公开材料中是否有人提过
  2. 五特征打分：命中几条？
  3. 差距评估：现有能力 vs 目标需求，差多少？
  4. 分级：A/B/C？
```

### Phase 5: 输出建议

```
输出格式：

候选方案 1：[产业A] → [目标技术B]
  - 物理同构：[一句话描述共同的原语]
  - 储备状态：[量产 / 实验室 / 论文阶段]
  - 差距：[差多少，可否短期弥补]
  - 分级：[A/B/C]
  - 产业隔离：[为什么不互通]

候选方案 2：...
推荐优先级排序：[A 级优先，B 级次之]
```

当需要更详细的行业数据时：

- 目标技术的原理与竞品现状：WebSearch 搜英文关键词
- 产业产能与技术水位：WebSearch 搜中文关键词 + "产能/工艺/量产"
- 交叉验证：搜"产业A关键词 + 产业B关键词"（中英文都搜），确认公开材料中是否有人提过

## 重要提醒

1. **不要被产品名限制**：同一个物理操作在不同产业里叫法完全不同——命名隔离是产业隔离的第一道墙。
2. **"低端"产业可能有"高端"能力**：看起来朴素的产业，可能在被忽视的某个维度上是领先的。
3. **极端工况行业是最大的隐性技术库**：深空、深海、重装、核电——这些领域在更苛刻的条件下解决过结构相似的问题，但与民用产业之间交流很少。
4. **A 级价值最高但最难发现**：需要跨越两个知识体系。B/C 级更容易找到，但先发窗口更短。
5. **案例只作演示**：上面 4 个案例是方法论的产出示例。真正交付时必须针对用户的具体问题重新做三步法，不要套用现成结论。
